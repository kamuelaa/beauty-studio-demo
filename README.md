# Beauty studio demo
Premium responsive sample studio concept built using the HTML/CSS/JavaScript + JSON/Pages CMS architecture of `kamuelaa/website-master-template-6.`. This is a separate repository; the master is unchanged.

Read [CLIENT_HANDOFF.md](CLIENT_HANDOFF.md) for Pages CMS, Setmore, Cloudflare Pages, and the missing-information checklist.

Serve the repository root with any static HTTP server. No build command or dependencies. Content is loaded from `content/*.json` and edited using `.pages.yml`. Booking is disabled unless a valid Setmore URL AND owner approval flag are supplied. Demo artwork is CSS illustration; no client photos, reviews, prices, or credentials are invented. All placeholders are explicitly marked. The optional gallery opens approved uploaded photos in an accessible native dialog.

Deployment is pending explicit user approval. Do not transfer ownership before final client approval and payment.
